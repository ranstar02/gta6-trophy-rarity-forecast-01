Forecasts every GTA VI trophy's Exophase earn rate at 2026-11-26T00:00:00Z as five quantiles. The model projects each trophy's earners and the players-tracked denominator separately on the logit scale, so launch-week refresh dilution and player progression pull each trophy in its own direction.

## Run it

```sh
python3 main.py
```
